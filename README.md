# nesting2d — 约束二维材料片的无重叠排样与共边切割段生成

离线制造几何工程用可复用模块:
1. 在整数网格板材上无重叠排样连通格子零件, 求最小使用高度;
2. 对已有合法排样结果生成**切割段**: 完全重合且切缝补偿相同的边只切一刀,
   保留涉及的零件 ID, 正确处理部分重合与内外轮廓。
**纯 Python 标准库实现, 从零编写, 不依赖任何第三方包。**

- Python 版本: **3.14.7**(仅标准库; 安装 Python 后无需安装任何其他依赖)
- 平台: Linux 原生; 核心、测试、演示全部离线, 不需要网络/账号/数据库/Docker

## 问题定义

- 板材: `width × height` 整数网格, 上限 **20 × 20**; 可含禁放格。
- 零件: 4-连通的格子集合, 每零件 ≤ **12** 格, 共 ≤ **12** 件。
- 每个零件可独立指定允许的旋转角度(`0/90/180/270` 的非空子集, 默认仅 `0`)
  与是否允许镜像(默认允许); `pack(..., allow_reflection=False)` 全局禁用镜像。
- **边距**: 任意两个不同零件的格子之间 Chebyshev 距离 ≥ 2
  (等价于每个零件按 Chebyshev 一格膨胀后互不相交)。
  **板外不计额外空间**: 零件可紧贴板材边缘; 膨胀掩码在板边界处裁剪。
  禁放格只禁止被零件格子覆盖, 不参与边距膨胀(可贴边、可落入零件孔洞)。
- **使用高度** `h`: 只使用板材底部 `h` 行(`0 ≤ y < h`), `1 ≤ h ≤ height`。

### 优化目标(按优先级)

1. 最小化使用高度 `h`;
2. 最小化旋转次数 `rotation_count` = 放置方向旋转角 ≠ 0 的零件个数
   (镜像不计入旋转次数);
3. 最小化布局坐标字典序: 按零件下标比较每个零件的
   `(x, y, (rotation_degrees, mirrored))`。

坐标系: `(x, y)`, `0 ≤ x < width`, `0 ≤ y < height`, y 向上。
`Placement(x, y)` 是该零件所取方向归一化形状(最小坐标为 `(0,0)`)的锚点。

## 接口

```python
from nesting2d import Board, Part, pack, Status, verify_layout, render_layout

board = Board(5, 5, forbidden=[(4, 3)])
parts = [
    Part([(0, 0), (1, 0), (2, 0), (3, 0)], rotations=(0, 90)),
    Part([(0, 0), (1, 0), (0, 1), (1, 1)]),          # 默认 rotations=(0,)
    Part([(0, 0), (1, 0), (0, 1), (1, 1)]),
]
res = pack(board, parts, budget=1_000_000, allow_reflection=True)
res.status          # Status.OPTIMAL / INFEASIBLE / BUDGET_EXHAUSTED
res.height          # 最优(或最优已知)高度; 无可行解为 None
res.placements      # tuple[Placement], 按零件下标排序
res.layout          # dict: part_index -> (x, y, rotation_degrees, mirrored)
res.rotation_count  # 旋转次数
res.lower_bound     # 已证明的下界(见下)
res.nodes, res.budget
```

辅助函数:

- `verify_layout(board, parts, placements, height) -> list[str]`:
  独立校验布局, 返回问题列表(空 = 合法)。
- `render_layout(board, parts, placements, height) -> str`:
  字符画(顶行在上; 零件 `0-9A-Za-z`, 禁放格 `#`, 空白 `.`)。
- `oriented_cells(cells, rotation_degrees, mirrored)`: 方向变换(与求解器同一代码路径)。

## 切割段生成

对**已有合法排样结果**生成最终切割直线段。范围限定: 有理坐标(`int`/
`Fraction`, 拒绝 float)、直边、固定端点排序; 暂不做热区优化, 也不联合
求解排样与切割次序。

### 数据结构与入口

```python
from fractions import Fraction
from nesting2d import (
    PolyPart, PolyPlacement, CutSegment, CutPlan,
    cut_segments, cut_segments_for_layout,
)

# 多边形零件: 外轮廓 + 0..4 个孔洞; 顶点为精确有理数(首尾不要重复,
# 重复也会被接受); 顺/逆时针均可, 内部归一化为外 CCW / 孔 CW。
host = PolyPart(
    outer=[(0, 0), (5, 0), (5, 5), (0, 5)],
    holes=[[(1, 1), (3, 1), (3, 3), (1, 3)]],   # 最多 MAX_POLY_HOLES=4 个
)
insert = PolyPart([(0, 0), (2, 0), (2, 2), (0, 2)])

# 放置只支持平移 (tx, ty); 每个零件恰好放置一次。
plan = cut_segments(
    [host, insert],
    [PolyPlacement(0, 0, 0), PolyPlacement(1, 1, 1)],
    kerf=0,                       # 默认切缝补偿宽度(非负有理数)
    kerfs={0: Fraction(1, 10)},   # 可选: 按零件下标覆盖
)
plan.segments      # tuple[CutSegment], 固定排序
plan.raw_edge_count  # 合并前轮廓边总数(外轮廓+孔洞)
plan.shared_count    # 共边只切一刀的段数
# CutSegment: p1, p2(端点, p1<p2), parts(涉及零件下标, 升序),
#             kerf(Fraction), shared(bool)
```

网格排样结果(`Part`/`Placement`, 可含孔零件如 3×3 环)可直接转换:

```python
res = pack(board, parts)
plan = cut_segments_for_layout(
    board, parts, res.placements, res.height,
    kerf=0, kerfs=None,
)
```

### 合并规则(精确)

1. 提取每个放置零件的全部轮廓边(外轮廓与孔洞分别成环)。
2. 任意边在与其他边的**交点**(含落在边内部的他边端点)处切分; 因此
   **部分重合不会被整条错误去重**, 只有真正重合的子段参与合并。
3. 同一几何子段: 当且仅当**切缝补偿 `kerf` 相同**才合并为一刀, 段上
   `parts` 保留全部涉及零件 ID; `kerf` 不同则分别成段。
4. 共线格点处的多余顶点会被合并(整条共边成为一刀), 但**角点/T 形接点
   保留**(连接点处存在其他方向的切割段时不合并)。
5. 端点固定按 `(x, y)` 字典序小者为 `p1`; 段表按 `(p1, p2, kerf)` 排序,
   输出完全确定、可复现。

内外轮廓: 同一零件的外轮廓与孔在几何上分离, 不会互相合并; 当一个零件
恰好嵌在另一零件的**孔洞**内时, 孔边与该零件外轮廓重合, 视为合法放置
且这四条边各只切一刀。

### 切割放置合法性

切割语义允许零件**沿边相接**(共边切割的前提), 因此不套用排样的一格
Chebyshev 边距。入口独立复核: 下标完整且不重复、放置后坐标非负、
方向被允许(网格入口)、在板/高度内且不覆禁放格(网格入口)、零件填充
区域无正面积重叠(允许贴边、点接触、孔洞内嵌)。任何不合法都报错,
不产生部分结果(结果只经返回值给出)。

### 切割相关错误语义

- `TypeError`: 坐标/切缝宽为 float(含 NaN/Infinity)、bool 充当 int、
  容器类型错误等;
- `InvalidSpecError`: 轮廓 <3 点、自交/退化共线、孔不在外轮廓内、孔互相
  交叠、超过 `MAX_CONTOUR_VERTICES=32`/`MAX_POLY_HOLES=4`、零件数超
  `MAX_PARTS`、放置下标缺失/重复/越界、负切缝宽、区域重叠、越界、
  覆盖禁放格等。

### 结果状态语义(预算耗尽与证明无解严格区分)

| 状态 | 含义 | height/placements | lower_bound |
|---|---|---|---|
| `OPTIMAL` | 高度与全部次序目标均已证明最优 | 最优解 | 等于 `height` |
| `INFEASIBLE` | 已证明任何高度(≤ 板高)都不可行 | `None` | `board.height + 1` |
| `BUDGET_EXHAUSTED` | 预算耗尽, **不假装最优** | 最优已知解(可能 `None`) | 已证明的下界 |

下界 = max(1, ⌈总面积/板宽⌉, 各零件最小包围盒高度的最大值)。
`budget` 以 DFS 节点数计, 所有高度的搜索共享同一预算; 耗尽时 `nodes`
为实际访问计数(可能等于 `budget + 1`, 触发中止的节点也计入)。

## 错误语义

不静默纠正任何非法输入, 错误消息含可定位字段路径:

- `TypeError`: 类型层面问题 —— 非 int 数值、**bool 充当整数**、
  **NaN/Infinity**、非 bool 的开关参数、错误容器类型等;
- `InvalidSpecError(ValueError)`: 取值域违规 —— 板尺寸超出 `[1, 20]`、
  零件为空/重复格/不连通/超过 12 格/超过 12 件、旋转角非 `0/90/180/270`、
  空旋转集、禁放格越界或重复、`budget < 1` 等。

`Part`/`Board` 在构造时(`__post_init__)完成全部校验并归一化为不可变
`frozenset`, 之后 `pack` 不会修改输入; 求解过程无可变全局状态,
失败不会留下部分变更(结果只通过返回值传递)。

## 设计取舍

- **位集回溯**: 每个候选放置预计算两个 Python int 位掩码(占用 + Chebyshev
  一格膨胀), 冲突检测为 O(1) 位运算; 膨胀在板边界裁剪(板外不计空间)。
- **等形对称去重**: 同一零件由对称性产生的相同方向只保留代表元
  (未镜像优先, 再按旋转角); 形状且允许方向完全相同的零件归为一组,
  搜索时同组候选下标单调不减以破缺对称。注意: 形状相同但允许旋转集不同
  的零件**不**同组(旋转次数目标不同, 不可互换)。
- **两阶段驱动**: 利用可行性关于高度的单调性 —— 先在整板高度下贪心取
  任一可行解(首叶即停, 同时整板不可行 ⇔ 整体不可行), 再从下界向上逐高度
  完整枚举, 首次完整枚举成功的高度即最优高度, 该高度的枚举同时完成
  旋转次数与字典序的次序优化。
- **MRV + 截断扫描**: 每节点选择可行候选最少的零件组; 扫描带计数截断。
- **预算语义**: 单一计数器贯穿所有阶段; 耗尽即抛内部异常并汇报
  最优已知解与下界, 绝不把未证明结果标记为 `OPTIMAL`/`INFEASIBLE`。
- **切割段切分/合并**: 全部用 :class:`fractions.Fraction` 精确运算(无
  浮点)。先对每条边收集它与其他边的全部内部交点(含他边落在其上的端
  点)切成原子段, 再按"几何原子段 + kerf"分组合并 —— 部分重合因此只会
  合并真正重合的子段。共线链在确认连接点无其他方向切割段后才接成整段
  (角点、T 形接点保留)。
- **内外轮廓方向约定**: 轮廓统一为"实体填充在有向边左侧"(外 CCW、
  孔 CW)。两条共线边方向相反 ⇔ 实体分居两侧 ⇔ 合法贴边(含零件嵌入对
  方孔洞); 方向相同 ⇔ 同侧重叠 ⇔ 判为非法。网格零件的轮廓用边界边追踪
  得到(鞍点按最左转弯分环), 与多边形零件共用同一合并/校验代码路径。

## 已知限制

- 本模块实现的是本题契约的有限子集(网格正交排样 + Chebyshev 一格边距;
  有理坐标直边零件的切割段生成), **不宣称兼容任何行业排样/数控切割标准**。
  切割部分不支持曲线/圆弧、任意角度(除网格零件的 90° 整数倍方向)、
  连续旋转的多边形零件(`PolyPlacement` 仅平移), 也不做热区优化与
  排样-切割次序联合求解(本次迭代按题面不要求)。
- 精确回溯排样最坏情况指数级; 接近 20×20/12 件上限的紧凑实例可能在
  默认预算(1,000,000 节点)内只能给出 `BUDGET_EXHAUSTED` + 最优已知解,
  这是设计内的诚实报告, 不是错误。调大 `budget` 可继续搜索。
- 切割几何的规模上限: 零件数 ≤ `MAX_PARTS=12`, 每个多边形轮廓 ≤
  `MAX_CONTOUR_VERTICES=32` 顶点、孔 ≤ `MAX_POLY_HOLES=4`; 切分求交为
  边对数的二次复杂度(题面规模下足够), 没有单列的大规模性能指标。
- **误差口径**: 排样全部为整数; 切割全部为精确有理数(`Fraction`),
  无任何浮点结果, 因此没有数值误差; 任何浮点坐标/切缝宽(包括
  NaN/Infinity)直接被拒绝。
- 测试中的独立参考实现 `tests/_reference.py`(排样逐格穷举)与
  `tests/_cut_reference.py`(切割段中点覆盖法)均只用于小规模交叉验证,
  与被测核心算法组织不同, 不是性能参照。
